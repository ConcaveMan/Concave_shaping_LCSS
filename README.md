## Code Organization

The codes/ directory contains all MATLAB source files used in the numerical studies. The function/ folder contains supporting functions, while the main scripts for generating the figures are located in the root code directory.

## Reproducibility

The revised manuscript contains Figure 1(a)–(f), corresponding to files f1–f6 in the repository.

To reproduce the figures:

* Execute figure1.m to generate Figure 1(a) (f1), which illustrates the comparison-law allocation profiles.
* Execute test1.m to generate Figure 1(b) (f2), showing Lyapunov-level actuation demand.
* Execute test2new.m to generate Figure 1(c) (f3) and Figure 1(d) (f4), corresponding to the windowed nominal-rate analysis and endpoint-relaxation results.
* Execute test3new.m to generate Figure 1(e) (f5) and Figure 1(f) (f6), corresponding to the comparison with optimal-decay CLF-QPs and the effective-slack analysis.

The figure filenames (f1–f6) match the six subfigures presented as Figure 1(a)–(f) in the revised manuscript.
