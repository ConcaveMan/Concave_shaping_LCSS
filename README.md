## Code Organization

The `codes/` directory contains all source files required for the experiments.
Within it, the `test/` subfolder provides three test scripts, while the `function/` folder contains the supporting function files.

## Reproducibility

To reproduce the results shown in Figure 1:

* Execute `test1.m` for Figure 1(a) and Figure 1(b).
* Execute `test2.m` for Figure 1(c) and Figure 1(d).
* Execute `test3.m` for Figure 1(e) and Figure 1(f).
